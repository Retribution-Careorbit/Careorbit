1. AZURE AI VISION (Document Intelligence)
   Package: azure-ai-documentintelligence==1.0.0
   Why this over Computer Vision: prebuilt-document model understands
   medical document layout (tables, key-value pairs, handwriting).
   Async polling is critical — OCR takes 3-8 seconds.

   Implementation pattern:
```python
   # services/azure_vision.py
   from azure.ai.documentintelligence.aio import DocumentIntelligenceClient
   from azure.core.credentials import AzureKeyCredential

   class AzureVisionService:
       def __init__(self):
           self.client = DocumentIntelligenceClient(
               endpoint=settings.AZURE_VISION_ENDPOINT,
               credential=AzureKeyCredential(settings.AZURE_VISION_KEY)
           )

       async def extract_text(self, image_bytes: bytes) -> OCRResult:
           async with self.client:
               poller = await self.client.begin_analyze_document(
                   "prebuilt-read",
                   analyze_request=image_bytes,
                   content_type="image/jpeg"
               )
               result = await poller.result()
           full_text = "\n".join(
               line.content
               for page in result.pages
               for line in (page.lines or [])
           )
           avg_confidence = sum(
               word.confidence
               for page in result.pages
               for line in (page.lines or [])
               for word in (line.words or [])
               if word.confidence
           ) / max(1, sum(
               len(line.words or [])
               for page in result.pages
               for line in (page.lines or [])
           ))
           return OCRResult(
               full_text=full_text,
               lines=[l.content for p in result.pages for l in (p.lines or [])],
               avg_confidence=avg_confidence,
               page_count=len(result.pages)
           )
```

2. AZURE OPENAI SERVICE (GPT-4o)
   Package: openai==1.35.0 (Azure OpenAI uses same package since v1.0)
   Why GPT-4o over GPT-3.5: medical entity extraction requires context
   understanding for Hindi/English drug names, dosage abbreviations (BD=twice daily).

   Implementation pattern:
```python
   # services/azure_openai.py
   from openai import AsyncAzureOpenAI

   class AzureOpenAIService:
       def __init__(self):
           self.client = AsyncAzureOpenAI(
               azure_endpoint=settings.AZURE_OPENAI_ENDPOINT,
               api_key=settings.AZURE_OPENAI_API_KEY,
               api_version="2024-02-01"
           )
           self.deployment = settings.AZURE_OPENAI_DEPLOYMENT  # "gpt-4o"

       async def extract_structured_data(
           self, ocr_text: str, doc_type: str
       ) -> dict:
           response = await self.client.chat.completions.create(
               model=self.deployment,
               messages=[
                   {"role": "system", "content": EXTRACTION_PROMPT[doc_type]},
                   {"role": "user", "content": ocr_text}
               ],
               response_format={"type": "json_object"},
               temperature=0.1,  # Low temperature for medical extraction
               max_tokens=2000
           )
           return json.loads(response.choices[0].message.content)
```

   Package: Use requests/httpx directly (no official async Azure Translator SDK)
   Why httpx over requests: native async support, same API surface.

   Implementation pattern:
```python
   # services/azure_translator.py
   import httpx

   class AzureTranslatorService:
       BASE_URL = "https://api.cognitive.microsofttranslator.com"

       async def translate(self, text: str, target: str, source: str = None) -> str:
           params = {"api-version": "3.0", "to": target}
           if source:
               params["from"] = source
           async with httpx.AsyncClient() as client:
               response = await client.post(
                   f"{self.BASE_URL}/translate",
                   params=params,
                   headers={
                       "Ocp-Apim-Subscription-Key": settings.AZURE_TRANSLATOR_KEY,
                       "Ocp-Apim-Subscription-Region": settings.AZURE_TRANSLATOR_REGION,
                   },
                   json=[{"Text": text}],
                   timeout=10.0
               )
           return response.json()[0]["translations"][0]["text"]
```

4. AZURE AI LANGUAGE (Healthcare NER)
   Package: azure-ai-textanalytics==5.3.0
   Why: Recognize medical entities with RxNorm/ICD-10 links directly from text.

   Implementation pattern:
```python
   from azure.ai.textanalytics.aio import TextAnalyticsClient

   async def recognize_health_entities(self, text: str) -> list[MedicalEntity]:
       async with TextAnalyticsClient(
           self.endpoint, AzureKeyCredential(self.key)
       ) as client:
           poller = await client.begin_analyze_healthcare_entities([text])
           result = await poller.result()
           entities = []
           async for doc in result:
               for entity in doc.entities:
                   entities.append(MedicalEntity(
                       text=entity.text,
                       category=entity.category,
                       confidence=entity.confidence_score,
                       rxnorm_id=next(
                           (l.id for l in entity.data_sources
                            if l.name == "RxNorm"), None
                       )
                   ))
           return entities
```

   Implementation pattern:
```python
   from azure.storage.blob.aio import BlobServiceClient

   async def upload_document(self, image_bytes: bytes, patient_id: str, doc_id: str) -> str:
       async with BlobServiceClient.from_connection_string(
           settings.AZURE_STORAGE_CONNECTION_STRING
       ) as client:
           container = client.get_container_client("prescriptions")
           blob_name = f"{patient_id}/{doc_id}.jpg"
           await container.upload_blob(blob_name, image_bytes, overwrite=True)
           # Generate time-limited SAS URL (1 hour)
           sas_token = generate_blob_sas(

               container_name="prescriptions",
               blob_name=blob_name,
               account_key=settings.AZURE_STORAGE_KEY,
               permission=BlobSasPermissions(read=True),
               expiry=datetime.utcnow() + timedelta(hours=1)

```

7. AZURE AI SEARCH (RAG for Drug Interactions + Guidelines)
   Package: azure-search-documents==11.6.0

   Index design:
   - drug_interactions index: drug_a, drug_b, severity, description,
     clinical_action, severity_modifiers (JSON), embedding (text-embedding-3-small)
   - clinical_guidelines index: condition, screening_type, frequency,
     evidence_grade, source, applicable_codes (ICD-10 array), embedding

   Implementation pattern:
```python
   from azure.search.documents.aio import SearchClient
   from azure.search.documents.models import VectorizedQuery

   async def search_drug_interactions(
       self, drug_a: str, drug_b: str
   ) -> list[DrugInteraction]:
       async with SearchClient(
           self.endpoint, "drug-interactions",
           AzureKeyCredential(self.search_key)
       ) as client:
           # Hybrid search: keyword + vector
           embedding = await self.get_embedding(f"{drug_a} {drug_b} interaction")
           vector_query = VectorizedQuery(
               vector=embedding, k_nearest_neighbors=3,
               fields="embedding"
           )
           results = await client.search(
               search_text=f"{drug_a} {drug_b}",
               vector_queries=[vector_query],
               filter=f"drug_a eq '{drug_a}' or drug_b eq '{drug_a}'",
               top=5
           )
           return [
               DrugInteraction(**result)
               async for result in results
               if result["@search.score"] > 0.7
           ]
```
